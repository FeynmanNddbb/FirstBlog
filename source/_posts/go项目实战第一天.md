# Go 随机数种子与版本变化总结

## 随机数种子的作用

- 随机数种子（Random Seed）是伪随机数生成器的“起点”，决定了随机数序列的起始位置。
- 相同的种子会生成相同的随机数序列，不同的种子会生成不同的序列。
- 在 Go 语言中，未设置种子时，默认行为会影响每次运行的随机数结果。

## Go 版本对随机数种子的影响

| Go 版本        | 随机数种子默认行为                   | 结果表现                   | 是否需要手动播种           |
|----------------|-------------------------------------|----------------------------|----------------------------|
| Go < 1.20      | 默认种子为固定值（如 1）            | 每次运行结果都一样         | 需要手动设置种子           |
| Go ≥ 1.20      | 自动使用系统随机源（如 /dev/urandom）| 每次运行结果都不同         | 不需要手动设置种子         |

## 代码示例

```go
import (
    "math/rand"
    "time"
)

func main() {
    // Go < 1.20 推荐手动播种
    rand.Seed(time.Now().UnixNano())
    println(rand.Intn(100))
}
```

> Go 1.20 及以后版本，math/rand 包自动播种，使用起来更方便，无需手动设置种子即可获得不同的随机数序列。
